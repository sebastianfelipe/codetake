## Transitive dependencies

The full Rust dependency tree (about 540 crates) is licensed under MIT,
Apache-2.0, Zlib, BSD, ISC, Unicode-3.0, Unlicense, CC0 or MPL-2.0 terms (the
MPL-2.0 crates are used unmodified; MPL-2.0 is file-level copyleft and
compatible with distributing an MIT application). To list every crate with
its license:

```sh
cd apps/desktop/src-tauri
cargo metadata --format-version 1 | jq -r '.packages[] | "\(.name) \(.version): \(.license)"' | sort
```

Release builds should ship a generated notice file (for example with
[cargo-about](https://github.com/EmbarkStudios/cargo-about)) that includes
each license's full text.

## Operating system frameworks

On macOS CodeTake uses Apple's system frameworks (ScreenCaptureKit,
AVFoundation, VideoToolbox, CoreMedia, CoreVideo, AudioToolbox,
CoreGraphics). They are part of macOS and are not redistributed.
